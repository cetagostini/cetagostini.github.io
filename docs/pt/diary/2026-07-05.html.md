# site novo, quem é

> Redesenhei o site todo. Verde, castanho, DAGs por todo o lado. Agora parece mesmo comigo.

By Carlos Trujillo

Source: https://cetagostini.github.io/pt/diary/2026-07-05.html

ok então acabei de publicar o redesign do site todo e honestamente? está incrível. tenho andado a mexer nisto há um tempo e finalmente está a sentir-se certo.

o site antigo era porreiro, suponho, mas não se sentia como *eu*. demasiado genérico, demasiado “feito por LLMs” o que… sim, literalmente era. agora é acolhedor e tem personalidade. as cores? completamente aleatórias. tinha uma boa foto recente com esta paleta — creme suave, verde discreto, algum castanho — e fui com isso. nenhuma filosofia de design profunda, só vibes.

fiz o novo com GLM 5.2. não é wow mas é funcional e gosto disso.

a cena dos DAGs é talvez a minha parte preferida? há um gráfico animado desvanecido por trás do meu nome na homepage e depois na página about a minha carreira real é um DAG. o que é parvo e nerd mas tipo… é esse o ponto. faço inferência causal. DAGs são a minha cena. mais vale abraçar a coisa.

ah e também fiz isto funcionar para LLMs. há um ficheiro `llms.txt`, espelhos em markdown limpo de todas as páginas, dados estruturados com JSON-LD. não faço ideia se o Google quer saber disto mas o ChatGPT e o Claude já conseguem ler o meu site por isso é fixe, suponho.

tudo isto é só quarto + GitHub Pages. renderiza a partir de computações congeladas por isso não tenho de ficar à espera que os notebooks corram cada vez que mudo uma vírgula. recomendo vivamente.

enfim. vou tentar escrever aqui regularmente a sério. vamos ver quanto tempo dura lol.
